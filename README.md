# Wandeling Cherapont - Belgische Ardennen 🥾🌲

Een prachtige, moderne webpagina over een wandeltocht van 5,7 km door de Belgische Ardennen bij Cherapont, langs de Ourthe Orientale.

## 🌟 Project Overzicht

Deze statische website presenteert een wandelroute met:
- Interactieve kaart van de route
- 7 foto's met uitgebreide beschrijvingen van bezienswaardigheden
- Route statistieken (afstand, hoogteverschil, geschatte tijd)
- Praktische tips voor wandelaars
- Volledig responsive design voor mobiel en desktop

## 📍 Route Informatie

- **Locatie**: Cherapont, Wallonië, België
- **Afstand**: 5,7 km
- **Hoogtewinst**: 109 m
- **Type**: Wandelroute
- **Geschatte tijd**: ±2 uur
- **Hoogtepunten**: 
  - Ourthe Orientale rivier en wetlands
  - Historische ruïnes in het bos
  - Steile bospaden met boomwortels
  - Open velden met panoramisch uitzicht
  - Bosbeheergebied

## 🎨 Design Kenmerken

### Kleurenpalet
- **Primary Green**: #2d6a4f (donkergroen voor titels)
- **Secondary Green**: #40916c (accentkleur)
- **Light Green**: #74c69d (highlights)
- **Very Light Green**: #d8f3dc (achtergronden)

### Typografie
- **Titels**: Playfair Display (serif, elegant)
- **Body tekst**: Open Sans (sans-serif, leesbaar)

### UI Componenten
- Sticky navigatiebalk met smooth scroll
- Hero sectie met gradient overlay
- Route statistieken in cards met icons
- Afwisselend links/rechts layout voor foto's
- Hover effecten en animaties
- Responsive grid layouts

## 🖼️ Foto Secties

1. **Route Kaart** - Overzicht van de 5,7 km route
2. **De Ourthe Orientale** - Rivier en wetland landschap
3. **Omhoog Door Het Woud** - Steile beklimming door het bos
4. **Door Open Velden** - Panoramisch uitzicht over weides
5. **Historische Ruïnes** - Mossbedekte stenen ruïnes
6. **Bosbeheer in de Ardennen** - Gevelde boomstammen
7. **Een Gezellige Groep** - Groepsfoto van de wandelaars

## 🛠️ Technologieën

- **HTML5**: Semantische structuur
- **CSS3**: Modern styling met Flexbox en Grid
- **JavaScript (ES6+)**: Interactiviteit en animaties

## ✨ Functionaliteiten

### Interactieve Elementen
- Smooth scrolling navigatie
- Navbar met scroll shadow effect
- Fade-in animaties bij scrollen
- Parallax effect in hero sectie
- Hover effecten op cards en afbeeldingen
- Responsive image loading

### Responsive Design
- **Desktop** (>768px): Twee-koloms layout voor foto's
- **Tablet** (768px): Aangepaste grid layouts
- **Mobiel** (<480px): Één-koloms layout, vereenvoudigde navigatie

## 📱 Browser Compatibiliteit

- Chrome/Edge (laatste versies)

- Safari (laatste versies)
- Mobiele browsers (iOS Safari, Chrome Mobile)

## 🚀 Gebruik

1. Open `index.html` in een webbrowser
2. Navigeer door de pagina via de sticky navbar
3. Scroll om de verschillende bezienswaardigheden te ontdekken
4. Alle afbeeldingen worden automatisch geladen
